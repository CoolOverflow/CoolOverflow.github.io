04 — Reserved

这里永远留一个位置

游戏厅是预留的可扩展模块：新游戏只要放进 games/<id>/，再往 data/games.json 里加一条记录，首页和这里就会自动多一张卡片。也可以直接把 Unity WebGL 导出放进 iframe。

查看添加文档 推荐一个玩法 
// data/games.json
{
  "id": "your-game",
  "title": "你的游戏",
  "path": "/games/your-game/",
  "status": "playable",
  "accent": "#7CFFB2"
}
