02 — Writing

最近在写

把学到的数学、图形学算法和引擎实现，写成能跑起来的代码与能看懂的文章。

全部文章

  1. 线性动态系统-卡尔曼滤波

    从概率图模型讲起，区分 HMM、卡尔曼滤波和粒子滤波各自适用的场景，再用条件概率一步步推导线性高斯系统的预测—校正递推，帮助你理解滤波为什么能降噪。 机器学习1 分钟#卡尔曼滤波#概率图模型

  2. 计算机图形学：Bresenham画线算法

    从斜率为 0 到 1 的简单情形出发，推导 Bresenham 画线算法的增量误差判别式，并给出覆盖四种斜率的 Python + turtle 完整实现，帮你搞懂直线光栅化如何逐像素选点。 图形学3 分钟#Bresenham#直线光栅化

  3. Python绘图工具turtle

    介绍 Python 自带绘图库 turtle 的基本用法，用爱心、L 系统分形、饼干和渐进多边形四个小例子，演示海龟移动、转向、填充与循环绘图技巧，适合作为绘图入门练习。 编程语言1 分钟#Python#turtle

  4. Lua语言学习1：基本语法和数据类型

    Lua 入门学习笔记：从安装与运行环境讲起，梳理 nil、table 等八种数据类型，再用可直接运行的示例说明赋值、循环、条件、函数与闭包等基本语法，适合快速上手速查。 编程语言3 分钟#Lua#语法基础

  5. 3D数学中角位移的表示：矩阵、欧拉角和四元数

    梳理三维旋转的三种表示：旋转矩阵、欧拉角与四元数的定义、换算思路和优缺点，并推导四元数的对数、指数、求幂与 slerp/squad 插值，帮你把 3D 数学基础打牢。 数学4 分钟#3D数学#四元数
